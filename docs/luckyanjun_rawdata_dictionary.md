# 原始数据集数据字典

> 数据集：UserBehavior.csv（淘宝用户行为数据集）
> 来源：阿里巴巴
> 版本：2017-11-25 ~ 2017-12-03
> 文档编制日期：2026-06-27（项目整理阶段）

---

## 一、数据集概述

| 属性 | 说明 |
|------|------|
| **完整名称** | Taobao User Behavior Dataset |
| **文件名** | `UserBehavior.csv` |
| **数据来源** | 阿里巴巴电商平台（淘宝） |
| **原始用途** | 隐式反馈推荐问题研究 |
| **记录总数** | 100,150,807 |
| **文件大小** | 3.5 GB |
| **时间跨度** | 2017-11-25 ~ 2017-12-03（共 9 天） |

| **采样方式** | 约 100 万随机用户全量行为 |
| **文件格式** | CSV，逗号分隔，无表头行，无引号包裹 |
| **字符编码** | UTF-8 |

## 二、字段定义

### 2.1 `user_id` — 用户 ID

| 属性 | 说明 |
|------|------|
| **字段名** | `user_id` |
| **数据类型** | BIGINT（整数） |
| **是否脱敏** | 是（原始用户 ID 序列化后） |
| **去重数量** | 987,994 |
| **取值范围** | 正整数（1 ~ 999,999 范围） |
| **业务含义** | 发起行为操作的脱敏用户标识 |
| **典型用法** | UV 计算、用户行为路径、留存队列分析 |

### 2.2 `item_id` — 商品 ID

| 属性 | 说明 |
|------|------|
| **字段名** | `item_id` |
| **数据类型** | BIGINT（整数） |
| **是否脱敏** | 是（原始商品 ID 序列化后） |
| **去重数量** | 4,162,024 |
| **取值范围** | 正整数 |
| **业务含义** | 被操作的脱敏商品标识 |
| **典型用法** | 商品热度排名、商品转化率分析 |

### 2.3 `category_id` — 商品类目 ID

| 属性 | 说明 |
|------|------|
| **字段名** | `category_id` |
| **数据类型** | BIGINT（整数） |
| **是否脱敏** | 是（原始类目 ID 序列化后） |
| **去重数量** | 9,439 |
| **取值范围** | 正整数 |
| **业务含义** | 商品所属的脱敏类目标识 |
| **典型用法** | 类目热度排名、类目转化效率分析 |
| **备注** | 原始数据不提供类目名称，类目名称为脱敏后的数字 ID |

### 2.4 `behavior_type` — 行为类型

| 属性 | 说明 |
|------|------|
| **字段名** | `behavior_type` |
| **数据类型** | STRING（枚举字符串） |
| **合法取值** | `pv`, `buy`, `cart`, `fav` |
| **大小写** | 清洗时统一转为小写 |

**行为类型枚举：**

| 取值 | 含义 | 数量 | 占比 | 业务说明 |
|------|------|------|------|----------|
| `pv` | 页面浏览（Page View） | 89,716,264 | 89.58% | 用户点击进入商品详情页 |
| `cart` | 加入购物车 | 5,530,446 | 5.52% | 用户将商品加入购物车 |
| `fav` | 收藏 | 2,888,258 | 2.88% | 用户收藏该商品 |
| `buy` | 购买 | 2,015,839 | 2.01% | 用户下单购买该商品 |

**行为漏斗关系：**
```
pv (浏览, 89.58%)                 ← 顶部流量入口
  ├─ cart (加购, 5.52%)          ← 强意向信号
  ├─ fav (收藏, 2.88%)           ← 兴趣信号
  └─ buy (购买, 2.01%)           ← 最终转化
```

### 2.5 `timestamp` — 时间戳

| 属性 | 说明 |
|------|------|
| **字段名** | `timestamp` |
| **数据类型** | BIGINT（整数） |
| **单位** | 秒级 Unix 时间戳 |
| **时区** | 北京时间 UTC+8 |
| **有效范围** | 1511544070 ~ 1512293891（实际首尾行） |
| **数据集声明的有效范围** | 1511500000 ~ 1512400000（北京时间 2017-11-25 00:00 ~ 2017-12-04 00:00） |
| **派生字段** | 清洗后生成 event_time, event_date, event_hour, weekday |
| **典型用法** | 时间序列分析、时段分布统计、留存计算 |

## 三、数据内容说明

### 3.1 数据集不包含的字段

该数据集**不提供**以下信息，因此分析中不应涉及：

- 价格/金额（无 GMV、销售额、客单价分析）
- 订单号（无法追踪单个订单）
- 商品名称、品牌、描述
- 用户性别、年龄、城市、会员等级
- 商品价格区间、折扣信息

### 3.2 数据行示例

```
1,2268318,2520377,pv,1511544070
1,2333346,2520771,pv,1511561733
1,2576651,149192,pv,1511572885
1,3830808,4181361,pv,1511593493
1,4365585,2520377,pv,1511596146
```

解读（第 1 行）：用户 `1` 在商品 `2268318`（类目 `2520377`）上执行了 `pv`（浏览）行为，时间为北京时间 `2017-11-25 01:21:10`。

## 四、数据质量报告

### 4.1 总体质量

| 指标 | 数值 | 百分比 |
|------|------|--------|
| 总行数 | 100,150,807 | 100% |
| 有效行数 | 100,131,827 | 99.98% |
| 无效行数 | 18,980 | 0.019% |

### 4.2 无效数据分类

| 跳过原因 | 预估数量 | 说明 |
|----------|----------|------|
| `bad_column_count` | 少量 | 列数不为 5（缺少字段或多余逗号） |
| `bad_type` | 少量 | 整数字段包含非数字字符 |
| `non_positive_id` | 318 | user_id / item_id / category_id ≤ 0 |
| `bad_behavior` | 少量 | behavior_type 不在 {pv, buy, cart, fav} |
| `bad_timestamp` | 少量 | timestamp ≤ 0 |
| `out_of_range_time` | ~18,662 | 时间超出 2017-11-25 至 2017-12-03 |

### 4.3 时间戳异常说明

原始数据中存在部分异常时间戳：
- **负值时间戳**（如 -2134949234）：Unix 时间戳为负，无法转换为有效日期 — 清洗时丢弃
- **远大于数据集范围的时间戳**（如 2122867355）：远超 2017-12-03 — 清洗时丢弃

## 五、清洗后数据集字段

清洗后（`cleanedDataset/user_behavior.csv`）在原始 5 个字段基础上，增加了 4 个派生时间字段：

| 字段 | 来源 | 类型 | 说明 |
|------|------|------|------|
| `user_id` | 原始 | BIGINT | 脱敏用户 ID（不变） |
| `item_id` | 原始 | BIGINT | 脱敏商品 ID（不变） |
| `category_id` | 原始 | BIGINT | 脱敏类目 ID（不变） |
| `behavior_type` | 原始 | STRING | 行为类型（统一小写） |
| `timestamp` | 原始 | BIGINT | 秒级时间戳（保留） |
| `event_time` | **派生** | TIMESTAMP | `yyyy-MM-dd HH:mm:ss` 格式北京时间 |
| `event_date` | **派生** | STRING | `yyyy-MM-dd` 日期 |
| `event_hour` | **派生** | INT | 0-23，行为发生的小时 |
| `weekday` | **派生** | INT | ISO 星期序号，1=周一，7=周日 |

## 六、数据使用约束

| 约束项 | 说明 |
|--------|------|
| **分析边界** | 无价格/金额字段，不涉及 GMV、销售额等分析 |
| **身份脱敏** | 所有 ID 均为序列化后，不可反推真实用户/商品/类目 |
| **时间范围** | 仅 9 天数据，不适用于长期趋势或季节性分析 |
| **采样偏差** | 约 100 万用户采样，非淘宝全量用户 |
| **行为定义** | 购买行为仅表示下单，不含支付确认和退款信息 |
| **数据时效** | 2017 年数据，仅供学习和研究，不反映当前淘宝业务 |
| **存储格式** | 原始 CSV 无表头、无引号，阅读时注意列索引 |
