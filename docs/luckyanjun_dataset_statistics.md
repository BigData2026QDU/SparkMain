### 2.3 行为类型分布

| 行为类型 | 数量 | 占比 | 说明 |
|----------|------|------|------|
| `pv` (浏览) | 89,716,264 | **89.58%** | 商品详情页浏览 |
| `cart` (加购) | 5,530,446 | **5.52%** | 加入购物车 |
| `fav` (收藏) | 2,888,258 | **2.88%** | 收藏商品 |
| `buy` (购买) | 2,015,839 | **2.01%** | 购买商品 |

**行为转化漏斗（全局）：**
```
PV (100%) → 意向[c+cart+fav] (8.41%) → 购买 (2.01%)
```

从浏览到购买的转化率约 **2.25%**；从意向（加购+收藏）到购买的转化率约 **23.94%**。

## 五、清洗规则摘要

| 规则 | 说明 |
|------|------|
| 列数校验 | 必须恰好 5 列 |
| 类型校验 | user_id, item_id, category_id, timestamp 必须为整数 |
| 正值校验 | 所有 ID 和 timestamp 必须 > 0 |
| 行为校验 | behavior_type 转为小写后必须在 {pv, buy, cart, fav} |
| 时间范围 | 仅限于北京时间 2017-11-25 ~ 2017-12-03 |
| 时区处理 | 时间戳按 UTC+8 转换为北京时间 |
| 派生字段 | 根据 timestamp 生成 event_time, event_date, event_hour, weekday |
| 输出校验 | 生产输出 ≥ 15000 行，≤ 500 MB |
